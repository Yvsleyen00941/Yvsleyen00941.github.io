Building Cockpit: A Zero-Cloud macOS & iPad Productivity HUD with Swift and SwiftUI

As developers and students, our daily workflow is constantly fragmented. In any given hour, we alternate between an editor, calendar notifications, music controls, Notion project trackers, and email threads.

Most modern tools attempt to solve this by introducing yet another Electron app or web dashboard that consumes 2GB of RAM and sends telemetry across third-party cloud servers. I wanted something fundamentally different: a purely native, zero-cloud productivity heads-up display (HUD) engineered specifically for the Apple ecosystem. That project is Cockpit.

The Vision: Turning the iPad into an Active Control Surface

The core philosophy behind Cockpit is treating the iPad resting next to your MacBook keyboard not as a secondary passive display, but as an active physical control surface:

  • Contextual Action Keys: Hotkeys adapt dynamically to whatever application has frontmost focus (Xcode, Safari, Terminal, Notion, Finder).
  • Four-Quadrant System Vitals: Real-time monitoring of local services, focus states, music playback, and calendar scheduling without opening browser tabs.
  • Daily Planner Engine: A unified morning briefing combining local calendar items, top-3 priorities, and local Pomodoro deep-work timers.

Architectural Breakdown

Cockpit is composed of two native Swift applications communicating seamlessly with zero third-party dependencies:

+-------------------------------------------------------------+
|                     macOS Workstation                       |
|  [ ControlCenter Helper (Daemon / Menu Bar Service) ]        |
|  - System Vitals, Calendar EventKit, Music ScriptingBridge  |
+-------------------------------------------------------------+
                             ▲
                             │ (End-to-End Encrypted TCP/USB)
                             ▼
+-------------------------------------------------------------+
|                      iPad / iOS Client                      |
|  [ Cockpit Touch HUD (SwiftUI + Live Activities) ]          |
|  - Real-time quadrant rendering, 120Hz ProMotion interaction|
+-------------------------------------------------------------+

1. Peer-to-Peer Local Connectivity

Instead of relaying data through remote cloud servers or external WebSockets, Cockpit establishes a direct peer-to-peer connection over local Wi-Fi or high-speed USB-C using Apple's Network.framework. All packets are end-to-end encrypted locally. If your internet goes down, your desk HUD remains 100% operational.

2. High-Performance SwiftUI Layout

Rendering rich data cards with sub-millisecond response requires avoiding unnecessary view graph recalculations. Cockpit isolates each quadrant (Vitals, Schedule, Focus, Media) into independent Observable models with targeted state projections, keeping 120Hz ProMotion animation fluid.

Installation via Homebrew

You can install Cockpit on macOS with a single terminal command through the official Homebrew tap:

brew install --cask Yvsleyen00941/tap/cockpit 📋
