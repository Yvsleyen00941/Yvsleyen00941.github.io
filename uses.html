Hardware, development tools, native software, and everyday gear.

💻 Hardware & Desk

  • Workstation: Apple Silicon MacBook Pro — optimized for rapid Swift builds and instant simulator execution.
  • Display: High-DPI external monitor calibrated for retina UI design and code readability.
  • Audio: Apple AirPods Pro for focus, active noise cancellation, and seamless macOS audio switching.
  • Input: Apple Magic Trackpad with custom gestures and mechanical keyboard with tactile switches.

🛠 Development & Engineering

  • IDE: Xcode for native macOS, iOS, and visionOS development with Instruments for memory profiling.
  • Editor: VS Code & Cursor with Geist Mono font and minimalist dark theme for web and systems documentation.
  • Terminal: Native macOS Terminal & zsh with custom aliases, Git integrations, and Homebrew.
  • Version Control: Git + GitHub CLI (gh) for open-source workflow and releases.

⚡️ Native macOS Applications

  • Cockpit: Self-engineered native macOS menu bar daemon & iPad productivity HUD (Cockpit on GitHub).
  • Rime: Liquid Glass PDF reader engineered specifically for macOS with multi-tab browsing and bookmark persistence (Rime on GitHub).
  • Raycast: System launcher, clipboard manager, and custom developer script executor.
  • Homebrew: Package management for macOS CLI utilities and self-hosted tap (homebrew-tap).

🎨 Design & Typography

  • Design Tool: Figma for user interface design, bento layouts, and design systems.
  • Typefaces: Geist Sans & Geist Mono (Vercel / Basel), Inter, and Apple SF Pro.
  • Design Philosophy: Native AppKit/SwiftUI feel, low-overhead micro-interactions, dark mode elegance, and zero-telemetry privacy.
